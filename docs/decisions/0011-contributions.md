## Context

The repository is public and all rights reserved (10). Fixes from others are welcome, but must not make anyone else an owner of the site.

## Decision

- **`CONTRIBUTING.md`** (`32ecf4c`): a contributor grants Ivan Vinski a perpetual, worldwide, non-exclusive, royalty-free, irrevocable license to their contribution, confirms it's theirs to give, and gains no other rights. Contributors aren't credited on the site.
- **The pull request template** has a checkbox agreeing to those terms.
- **Welcome:** fixes, accessibility, performance and typos. Design, copy and content are Ivan's, so they need an issue first.

## Alternatives

- **A copyright assignment:** the strongest, but weak as a checkbox in some countries.
- **A CLA bot** (CLA Assistant): a signed record per contributor, but setup and friction a personal site doesn't need yet.

## Consequences

- If outside contributions grow, the hosted CLA Assistant can be added without a workflow.
