## Context

The repository is public, so its code can be read, but the site and its writing are Ivan Vinski's work. It also holds code by others, and for a while the AGPL-licensed Spotcraft.

## Decision

- **All rights reserved** (`590903d`): the repository's own code and all of vin.ski's content (text, posts, project write-ups, images and portraits), wherever it's stored. Reading is allowed, as is what GitHub's terms allow (viewing and forking on GitHub); reuse needs written permission.
- **Third-party code keeps its own license,** listed with its notices in `THIRD_PARTY_NOTICES.md` and kept next to the code it covers.
- **Trademarks:** the vin.ski and Spotcraft names and logos.
- The licenses are in `LICENSE` and `apps/website/LICENSE`, explained in the README's License & Trademarks.

## Alternatives

- **An open-source license** for the site's code: others could reuse the site as theirs.
- **A private repository:** the code would stop being part of the portfolio.

## Consequences

- The repository is source-available, not open source.
- Contributions need terms that keep this true (11).
